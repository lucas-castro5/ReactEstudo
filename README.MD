## 📖 Sobre

Este repositório reúne exercícios, exemplos e pequenos projetos desenvolvidos durante meus estudos em **React**.

O objetivo é consolidar conhecimentos por meio da prática, explorando desde os fundamentos da biblioteca até conceitos mais avançados utilizados no desenvolvimento de aplicações modernas.

---

## 🎯 Objetivos

- Aprender React na prática
- Desenvolver componentes reutilizáveis

- Trabalhar com formulários e eventos

## 💻 Como Executar

### Clone o repositório

```bash
git clone https://github.com/lucas-castro5/ReactEstudo.git
```

### Entre no diretório desejado

```bash
cd ReactEstudo
```

### Instale as dependências

```bash
npm install
```

### Execute o projeto

```bash
npm start
```

### Abra no navegador

```text
http://localhost:3000
```
